Lessons Learned

Gotchas
01

DA drops cell-less pictures

A hero row must be row → cell → picture, or Document Authoring silently strips the image.

02

AEM lowercases the content bus

Any uppercase path 404s — author, link and redirect everything in lowercase.

03

The disclaimer gate poisons scraping

Suppress the UK-resident gate via cookies; never click Agree — it redirects every capture to home.

04

Images need absolute URLs

DA can't sideload root-relative paths — every image src must be an absolute http(s) URL.

05

The CDN edge lags fresh block CSS

Verify code on the origin or in the browser, not curl; new styling lands on edge revalidation.

06

DA strips arbitrary classes

Classes survive only on block wrappers; style content through structural selectors instead.
